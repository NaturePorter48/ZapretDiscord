> Антивирусная программа может среагировать на WinDivert.  
> Этот компонент нужен zapret для перехвата и фильтрации трафика.
> WinDivert способен использоваться как легитимными, так и вредоносными программами, однако сам по себе вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует компоненты WinDivert как потенциально опасные или относящиеся к хакерским инструментам. В результате файл может быть удалён и помещён в карантин. Название детекта обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо выключите проверку PUA (потенциально нежелательных приложений). В Kaspersky, например, это настройка "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше добавить папку в исключения. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Подготовка и запуск

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox откройте настройки "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query` — поставщик Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется.
    * Владельцам роутеров Keenetic нужно включить в настройках опцию "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать некорректно.

2. Загрузите zip- или rar-архив с [последней страницы релиза](https://github.com/NaturePorter48/zapret-discord-youtube/releases/latest).

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять.

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл:
    * Для поиска рабочей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для добавления стратегии в автозапуск: **`service.bat`** -> `Install Service` -> *выберите нужную стратегию*.

## ℹ️Назначение файлов и пунктов меню

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящий вариант**.

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск Windows (services.msc).</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из служб.
  - **`Check Status`** — показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — включает или выключает обход для игр и других служб, использующих UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Состояние функции отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — меняет режим обработки сервисов из `ipset-all.txt`.  
  Пункт полезен при проверке ресурса, который без zapret открывается, а с ним — нет.  
  Возможные состояния:
    - `none` — ни один IP не проходит проверку
    - `loaded` — проверяется принадлежность IP списку
    - `any` — фильтруется любой IP  
  - **`Auto-Update Check`** — включает или отключает автоматический поиск обновлений.
  - **`Replace active fakes`** — меняет выбранный используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** — заменяет `ipset-all.txt` актуальной версией из репозитория.
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>.
  - **`Check for Updates`** — вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** — ищет распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы приложения.
  - **`Run Tests`** — запускает проверку стратегий:
    - `Standard tests` — тестирует сайты из `utils/targets.txt`.
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Частые вопросы и неисправности

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно увидеть в панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/NaturePorter48/zapret-discord-youtube/issues/522).

### Не удалось подобрать стратегию
- Откройте командную строку с правами администратора.
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота.
  - С правами администратора откройте текстовым редактором файл `hosts` в созданной папке.
  - Вставьте скопированное содержимое в конец `hosts` или замените ранее добавленные аналогичные строки.
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Результат не гарантируется. При отсутствии эффекта используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/NaturePorter48/tg-ws-proxy) или одним из публичных прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> После обнаружения конкретная стратегия может перестать работать, даже если раньше некоторое время справлялась.
> В репозитории собрано много вариантов обхода. Если готовые конфигурации не подходят, создайте новую на основе одной из них, изменив параметры. Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте результаты `service.bat` -> `Run Diagnostics` и устраните найденные ошибки.

- Убедитесь, что нужный адрес присутствует в списках доменов или IP.

- Переключитесь на другие варианты, включая **`ALT`** и **`FAKE`**.

- Выполните полную переустановку по инструкции ниже.

- Дополнительная информация: [#765](https://github.com/NaturePorter48/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление
- Сохраните добавленные вами ресурсы и другие данные.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; если будут ошибки, исправьте их и в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежий архив `zapret-discord-youtube-...` со [страницы релизов](https://github.com/NaturePorter48/zapret-discord-youtube/releases).
- Щёлкните по архиву правой кнопкой мыши и откройте свойства. Если внизу справа есть флажок разблокировки, установите его, нажмите применить и затем ОК.
- Распакуйте архив в новый каталог в корне диска, исключив пробелы, специальные символы и кириллицу.
- По очереди проверяйте разные скрипты `general`. Если интернет-ресурсы не работают, завершите программу через значок замка в панели задач и запустите другую стратегию.
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение перестали работать при включённом zapret

- В `service.bat` проверьте, что `Game Filter` установлен в **`disabled`**, а `IPSet Filter` — в **`none`**. В противном случае фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Найдите имя службы в командной строке Windows, открытой через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не загружается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ уже работал.
- См. также [#251](https://github.com/NaturePorter48/zapret-discord-youtube/discussions/251).

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fиспользование).
- Сначала определите стратегию, с которой открывается YouTube, и запустите её.
- Откройте `service.bat` -> `Run Diagnostics` и очистите кэш Discord.
- Проверьте, изменилось ли поведение приложения после очистки.
- Откройте Discord в браузере по адресу https://discord.com/app. Если браузерная версия работает, используйте её.
- Если сайт также не открывается, повторно проверьте все стратегии: одна конфигурация может открывать YouTube, но не Discord.
- Дополнительные сведения: [#252](https://github.com/NaturePorter48/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/NaturePorter48/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси из интернета.

### Не запускаются игры или отсутствует доступ к ним

Игры используют разные схемы подключения, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальный порядок действий:
- Через `service.bat` обновите ipset и включите `Game Filter`.
- Если этого недостаточно, дополнительно включите `ipset any`.

Учитывайте, что режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите все IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/NaturePorter48/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящего ответа

- Опишите проблему [здесь](https://github.com/NaturePorter48/zapret-discord-youtube/issues).

## 🗒️Как добавить адреса других ресурсов

Нужные адреса можно добавить в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Это пригодится, например, когда IP-сеть уже указана в `ipset-all.txt`, но конкретный домен фильтровать не требуется.
- **`ipset-all.txt`** — IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
